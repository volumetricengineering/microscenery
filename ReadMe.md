# Microscenery

### Requirements
* JDK of Java 17 or higher installed
* up-to-date graphics drivers with Vulkan support

### Building open source version

- in gradle.properties set `withZenSysConCon=false`
- import into Jet brains IDEA and runn one of the scenes in the test folder of the frontend module
- or call `.\gradlew build` and .\gradlwe [name of the scene e.g. DemoHWScene]
